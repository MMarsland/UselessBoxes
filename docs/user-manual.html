Official User Manual

Useless Box

Basic setup and everyday operation guide for your connected paired Useless Box system.

Power: Barrel Jack or USB-C Wi-Fi Connected Pairing Customizable RGB, Buzzer, Motor

1. Product Overview

The Useless Box is a playful, internet-connected mechanical device designed to interact with a paired box. When connected to Wi-Fi, each box can influence the other box's active or inactive state.

Each unit includes:

  • A physical switch for local activation and deactivation.
  • RGB lighting effects for active and inactive states.
  • Buzzer sound patterns for activation feedback.
  • A rear settings button for menu navigation and customization.

2. Powering The Box

1
Connect power using either the provided Barrel Jack connector or a USB-C cable.
2
Wait for startup. The box will attempt to connect to its configured home Wi-Fi automatically.
3
After successful Wi-Fi connection, the box begins interacting with the paired box.

If the box fails to connect to Wi-Fi, there may currently be no visible status indicator. For support, contact Michael Marsland.

3. Basic Use

A
Push the front switch forward to activate the box.
B
Push the switch back to deactivate your box locally.
C
Keeping the switch back leaves your box inactive, which is useful when you do not want to be disturbed.

4. Rear Button Menu Controls

  • Short press in main menu: move to the next setting.
  • Long press in main menu: enter that setting submenu.
  • Short press in submenu: cycle through available options.
  • Long press in submenu: confirm current option and return to main menu.

Tip: Use short presses to browse quickly, then long press only when you want to save.

5. Settings Directory

Menu Item Description
1. Active RGB Colour Chooses the RGB pattern shown while your box is active.
2. Inactive RGB Colour Chooses the RGB pattern shown while your box is inactive.
3. RGB Brightness Adjusts LED brightness from 0% to 100% in 10% increments.
4. Active Buzzer Sound Selects buzzer pattern used when the box becomes active.
5. Inactive Buzzer Sound Selects buzzer pattern used when the box becomes inactive.
6. Motor Speed Adjusts motor power from 40% to 100% in 10% increments.
7. Solo Mode Toggles standalone operation On or Off.

6. Behavior Notes

  • The box uses separate RGB behavior for active vs inactive states.
  • The buzzer can be set to short one-time effects or looping patterns.
  • Settings are stored on the box so your choices remain after restart.

7. Solo Mode

Solo Mode lets the box behave like a traditional standalone Useless Box. While Solo Mode is enabled, local switch actions do not affect the paired box.

8. Programming / Firmware Updates

To program the box, connect it to a computer using USB-C and follow the project instructions in the repository README.md.
